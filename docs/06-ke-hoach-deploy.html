2.Sơ đồ

Một máy ảo duy nhất chạy lại đúng Docker Compose hiện có, thêm một dịch vụ Caddy đứng trước để cấp chứng chỉ HTTPS miễn phí và chuyển tiếp vào app. Không dùng Load Balancer, Cloud SQL hay Cloud DNS (đều tính phí).

  • Chỉ Caddy mở cổng ra Internet (80, 443). App và database chỉ nói chuyện trong mạng nội bộ của Docker.
  • Cổng 80 chỉ để Let's Encrypt cấp chứng chỉ và tự chuyển hướng sang HTTPS.
  • Người vận hành vào máy bằng gcloud compute ssh --tunnel-through-iap, cổng 22 không mở ra Internet.

3.Cấu hình Free Tier

Free Tier "Always Free" của Compute Engine áp dụng cho 1 máy e2-micro mỗi tháng ở 3 vùng của Mỹ. Cấu hình dưới đây giữ trong hạn mức đó. Hạn mức có thể thay đổi: kiểm tra lại trang giá chính thức ngay trước khi tạo.

4.Máy chỉ 1 GB RAM: swap và giới hạn bộ nhớ

Ngân sách RAM

Thành phầnGiới hạn
Debian + Docker~250 MB
db (PostgreSQL)256 MB
app (Node.js)192 MB
caddy64 MB
Còn dư~200 MB
Swap trên đĩa2 GB

Swap đỡ lúc build image (npm ci) và lúc đột biến. Swap nằm trong 30 GB đĩa, không tốn thêm tiền.

Tinh chỉnh PostgreSQL cho máy nhỏ

  • shared_buffers=64MB
  • work_mem=2MB, maintenance_work_mem=32MB
  • max_connections=20 (app dùng tối đa 10 kết nối)
  • effective_cache_size=192MB

Node.js

  • NODE_OPTIONS=--max-old-space-size=128

Hệ điều hành

  • vm.swappiness=10: chỉ dùng swap khi thật cần.
  • Log Docker xoay vòng (max-size 10m, max-file 3) để không đầy đĩa.

Tạo swap 2 GB (chạy trên máy ảo, bước 6.6)

sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
echo 'vm.swappiness=10' | sudo tee /etc/sysctl.d/99-swap.conf
sudo sysctl --system

Phác thảo compose.prod.yaml (để duyệt, chưa tạo file)

services:
  caddy:
    image: caddy:2-alpine
    ports: ["80:80", "443:443"]
    environment: { DOMAIN: ${DOMAIN} }
    volumes: [ "./Caddyfile:/etc/caddy/Caddyfile:ro", "caddy-data:/data" ]
    depends_on: [app]
    deploy: { resources: { limits: { memory: 64m } } }
    restart: unless-stopped
  app:
    ports: !reset []                     # không mở 3000 ra máy
    environment:
      NODE_OPTIONS: --max-old-space-size=128
      COOKIE_SECURE: "1"
      TRUST_PROXY: "1"                   # T3
      NOI_DUNG_DIEU_KHOAN: ${NOI_DUNG_DIEU_KHOAN}
      PHIEN_BAN_DIEU_KHOAN: ${PHIEN_BAN_DIEU_KHOAN}
    deploy: { resources: { limits: { memory: 192m } } }
  db:
    command: postgres -c shared_buffers=64MB -c work_mem=2MB -c max_connections=20
             -c maintenance_work_mem=32MB -c effective_cache_size=192MB
    deploy: { resources: { limits: { memory: 256m } } }
volumes:
  caddy-data:

# Caddyfile
{$DOMAIN} {
  encode gzip
  reverse_proxy app:3000
}

6.Các bước deploy và cách kiểm tra

Lệnh chạy trên máy anh/chị (PowerShell, đã có gcloud) trừ khi ghi "trên máy ảo". Thay [PROJECT_ID], [domain]. Mỗi bước có phần Kiểm tra; chỉ sang bước sau khi kiểm tra đạt.

6.1Chọn project và bật API

gcloud config set project [PROJECT_ID]
gcloud services enable compute.googleapis.com iap.googleapis.com
Kiểm tra gcloud config get-value project ra đúng project · gcloud billing projects describe [PROJECT_ID] có billingEnabled: true · gcloud services list --enabled có compute.googleapis.com.

6.2Đặt cảnh báo ngân sách (trước khi tạo tài nguyên)

Trên trang Billing → Budgets & alerts: tạo ngân sách nhỏ (ví dụ 25.000 ₫/tháng) cho project, cảnh báo email ở 50%, 90%, 100%. Cảnh báo không tự dừng dịch vụ, chỉ báo để kịp xử lý.

Kiểm tra Budget hiện trong danh sách, đúng project, có email nhận cảnh báo.

6.3Giữ IP tĩnh

gcloud compute addresses create dcc-ip --region=us-central1
gcloud compute addresses describe dcc-ip --region=us-central1 --format="value(address)"
Kiểm tra Có một địa chỉ IPv4, trạng thái RESERVED. Ghi lại để dùng ở 6.5 và 6.8. Lưu ý: IP giữ mà không gắn vào máy đang chạy thì bị tính phí → làm tiếp 6.5 ngay.

6.4Tường lửa

gcloud compute firewall-rules create dcc-allow-web --network=default --direction=INGRESS ^
  --allow=tcp:80,tcp:443 --source-ranges=0.0.0.0/0 --target-tags=web
gcloud compute firewall-rules create dcc-allow-ssh-iap --network=default --direction=INGRESS ^
  --allow=tcp:22 --source-ranges=35.235.240.0/20 --target-tags=web
gcloud compute firewall-rules delete default-allow-ssh default-allow-rdp
Kiểm tra gcloud compute firewall-rules list: có 2 luật dcc-*; không còn luật mở 22 hay 3389 cho 0.0.0.0/0.

6.5Tạo máy ảo

gcloud compute instances create dcc-vm --zone=us-central1-a --machine-type=e2-micro ^
  --image-family=debian-12 --image-project=debian-cloud ^
  --boot-disk-type=pd-standard --boot-disk-size=30GB ^
  --address=dcc-ip --tags=web ^
  --shielded-secure-boot --shielded-vtpm --shielded-integrity-monitoring
Kiểm tra gcloud compute instances describe dcc-vm --zone=us-central1-a --format="value(machineType,status,disks[0].diskSizeGb)" ra e2-micro, RUNNING, 30 · gcloud compute disks describe dcc-vm --zone=us-central1-a --format="value(type)" kết thúc bằng pd-standard.

6.6Vào máy, thêm swap, cài Docker, bật cập nhật bảo mật

gcloud compute ssh dcc-vm --zone=us-central1-a --tunnel-through-iap

Trên máy ảo: tạo swap (mục 4), rồi cài Docker từ kho chính thức của Docker cho Debian, thêm user vào nhóm docker, cài unattended-upgrades, cấu hình xoay vòng log trong /etc/docker/daemon.json.

Kiểm tra trên máy ảo: free -h thấy Swap 2.0Gi · docker version và docker compose version chạy được · systemctl is-enabled unattended-upgrades ra enabled.

6.7Lấy code và tạo .env trên máy ảo

git clone --branch [nhánh-deploy] https://github.com/nguyenthaotu-wendy/vibe-test.git dcc
cd dcc
cp .env.production.example .env
chmod 600 .env
nano .env        # đặt DOMAIN, mật khẩu DB và admin MỚI, điều khoản thật
Kiểm tra ls -l .env ra quyền -rw------- · mật khẩu admin ≥ 12 ký tự, khác mật khẩu trên máy cá nhân · COOKIE_SECURE=1.

6.8Trỏ tên miền

Ở nơi quản lý DNS của [domain]: tạo bản ghi A → IP ở 6.3, TTL 300. Không dùng Cloud DNS (tính phí theo vùng DNS).

Kiểm tra nslookup [domain] trả về đúng IP tĩnh (có thể mất vài phút đến vài giờ).

6.9Khởi động

docker compose -f compose.yaml -f compose.prod.yaml up -d --build
Kiểm tra trên máy ảo: docker compose ps → caddy, app, db đều Up, app và db healthy · docker stats --no-stream mỗi dịch vụ dưới giới hạn RAM · docker compose logs caddy có dòng chứng chỉ đã cấp cho [domain].

6.10Kiểm tra từ bên ngoài

curl -I http://[domain]          # 301/308 → https
curl https://[domain]/healthz     # ok
curl -I https://[domain]/admin    # 302 → /admin/dang-nhap
Kiểm tra mở https://[domain] trên điện thoại: có ổ khoá HTTPS, bấm Bắt đầu ra form · đăng ký bằng dữ liệu giả, chơi 1 lượt, đăng nhập /admin thấy người vừa đăng ký rồi xoá dòng thử · cookie dcc_admin có Secure · thử sai mật khẩu 5 lần từ 4G: chỉ IP đó bị khoá, máy khác vẫn đăng nhập được (xác nhận T3).

6.11Sao lưu hằng ngày

Cron trên máy ảo chạy scripts/sao-luu.sh lúc 02:00, lưu ~/sao-luu/*.sql.gz, giữ 7 bản. Tải về máy cá nhân khi cần: gcloud compute scp --tunnel-through-iap dcc-vm:~/sao-luu/[file] . --zone=us-central1-a.

Kiểm tra sau 1 ngày có file mới · thử khôi phục 1 bản vào database tạm trên máy cá nhân để chắc bản sao lưu dùng được.

9.Xoá sạch sau khoá học

  1. Lấy dữ liệu cần giữ (nếu có): xuất CSV từ /admin hoặc tải bản sao lưu mới nhất về. Xử lý theo điều khoản đã cam kết; xoá dữ liệu cá nhân không còn cần.
  2. Gỡ bản ghi DNS A của [domain] trỏ về IP (tránh tên miền trỏ vào IP sau này thuộc người khác).
  3. Xoá tài nguyên (máy cá nhân, PowerShell): 
    gcloud compute instances delete dcc-vm --zone=us-central1-a --delete-disks=all
gcloud compute addresses delete dcc-ip --region=us-central1
gcloud compute firewall-rules delete dcc-allow-web dcc-allow-ssh-iap
  4. Kiểm tra không còn gì tính phí: 
    gcloud compute instances list
gcloud compute disks list
gcloud compute addresses list
gcloud compute snapshots list

10.Phương án miễn phí đã chọn: Render + Neon

Google Cloud yêu cầu tài khoản thanh toán nạp trước tối thiểu 800.000 ₫ mới mở được (tài khoản đang ở trạng thái "closed"), kể cả khi chỉ dùng Free Tier. Vì vậy chọn phương án không cần nạp tiền và vẫn gắn được tên miền riêng. Các mục 1–9 giữ lại để dùng khi chuyển sang Google Cloud sau này.

Thay đổi code cho phương án này

  • server/lib/db.js: hỗ trợ DATABASE_URL; SSL bật và kiểm tra chứng chỉ khi máy chủ database không phải nội bộ; chờ kết nối 15 giây (Neon thức dậy từ trạng thái ngủ); số kết nối tối đa đặt qua DB_POOL_MAX.
  • server/server.js: thêm TRUST_PROXY_HEADER và TRUST_PROXY_HOPS. Trên Render (sau Cloudflare), X-Forwarded-For có dạng [giá trị người dùng tự gửi…, IP thật, Cloudflare, Render nội bộ], nên đọc cf-connecting-ip (Cloudflare luôn ghi đè), dự phòng phần tử thứ 3 từ cuối. Đã kiểm tra 18/11/2026: 11 lần đăng ký với IP giả mạo khác nhau → lần thứ 11 bị chặn (429).
  • render.yaml: dịch vụ dap-chim-canh-cut, gói free, /healthz, biến môi trường.
